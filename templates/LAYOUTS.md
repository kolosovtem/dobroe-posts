# Каталог макетов картинок

Рендер: `python3 -I templates/render.py config.json out.jpg`. Полные примеры конфигов - в `templates/examples/<layout>.json`, превью всех макетов - `templates/examples/_all_layouts.jpg`.

Общие поля: `layout`, `label` (метка справа сверху), `title` (`[[акцент]]`, `\n` - перенос), `accent` (violet/orange/cyan/mint/pink), `icon` (пиксельная иконка), `source`, `ribbon` (слова бегущей строки).

Иконки: star check cross chart search chat phone target bolt eye coin clock mail play megaphone trophy cursor heart arrow bag bulb

| Макет | Для чего | Обязательные поля | Доп. поля |
|---|---|---|---|
| `stat` | исследование с сильной цифрой | big, title, rows **или** stats | chip, card_title, subtitle, unit |
| `news` | новость площадки/рынка | title, watermark (слово-фон, напр. TELEGRAM) | subtitle, facts [[значение, подпись]] x2-3, icon |
| `dark` | острый вопрос, совет, провокация | title | subtitle, watermark, icon, cta |
| `marquee` | короткий совет/мысль | title | kicker, subtitle, icon, ribbon |
| `checklist` | чек-лист 3-6 пунктов | title, items | kicker, save |
| `myth` | разбор мифа | myth, truth | items (до 3), source |
| `compare` | было/стало, плохо/хорошо | title, left{title,items}, right{title,items} | verdict |
| `quote` | цитата эксперта/источника (только реальная!) | quote, author | role, icon |
| `chat` | Telegram-боты, продажи, ответы клиентам | title, messages [[in/out, текст, время]] | chat_title, chat_status |
| `pixel` | лёгкий/игровой пост, привычки, лайфхаки | title (коротко!), icon | items (до 4), label, progress |
| `steps` | инструкция 3-5 шагов | title, items [[шаг, пояснение]] | kicker |
| `hero` | как первый экран сайта: заголовок + большая иллюстрация агентства | title, art (cow / bucket / plane) | kicker, subtitle, cta |
| `team` | посты про агентство, подход, команду, ценности | title | kicker, subtitle, ribbon (слова с точкой: "SEO.") |
| `offer` | последний слайд карусели: услуга агентства по теме + контакты | title | kicker, items (до 4 пунктов, что сделаем), cta ("Напишите нам:"), art (маленькая иллюстрация), accent |

Карусель: `python3 -I templates/carousel.py carousel.json <папка>`, конфиг `{"slides": [...]}` из 3-6 слайдов, последний - `offer`. Пример - `templates/examples/carousel.json`.

## Иллюстрации агентства (`art`)
Файлы в `assets/img/`. Это фирменные картинки с сайта dobroe.agency - использовать можно и нужно, но не чаще одного раза на 6 постов каждую.
- `cow` - корова выглядывает из монитора: внимание, видимость, «заметят ли вас», SEO, выделиться среди конкурентов.
- `bucket` - дырявое ведро: утечки заявок/бюджета, потерянные клиенты, воронка, аналитика.
- `plane` - бумажный самолётик с тенью истребителя: малый бюджет против крупных, амбиции, рост, стартап.
- `team` - только для макета `team`.
- Маленькие иллюстрации (поле `art` в макетах `news`, `marquee`, `quote`, `offer` вместо пиксельной иконки):
  `ill_handshake` (партнёрство, доверие), `ill_layers` (комплексный подход, всё в одном), `ill_calendar` (контент-план, сроки),
  `ill_brain` (стратегия, ИИ, идеи), `ill_flow` (процессы, автоматизация, боты), `ill_sliders` (настройка рекламы, гибкость),
  `ill_people` (аудитория, сообщество, комментарии), `ill_battery` (ресурс, выгорание, эффективность).

## Примеры

### chat
```json
{
 "layout": "chat",
 "label": "TELEGRAM-БОТ",
 "title": "Бот отвечает, пока [[вы спите]]",
 "chat_title": "Бот записи",
 "messages": [
  [
   "in",
   "Здравствуйте! Можно записаться на субботу?",
   "23:41"
  ],
  [
   "out",
   "Конечно! Свободно 11:00, 13:30 и 16:00. Какое время удобно?",
   "23:41"
  ],
  [
   "in",
   "13:30",
   "23:42"
  ],
  [
   "out",
   "Готово, вы записаны. Напомню за день до визита",
   "23:42"
  ]
 ]
}
```
