# dobroe-posts

Картинки и тексты постов Instagram @dobroe.agency (Агентство Добрых Дел, Бишкек).
Файлы отсюда Instagram забирает по публичной ссылке:
`https://raw.githubusercontent.com/kolosovtem/dobroe-posts/main/posts/<папка>/post.jpg`

## Структура
- `templates/post.py` — шаблон картинки 1080×1350 (запуск: `python3 -I templates/post.py config.json out.jpg`, описание полей в начале файла)
- `assets/logo_grid.png` — настоящий пиксельный логотип агентства (не заменять, не рисовать свой)
- `posts/<YYYY-MM-DD-HHMM>/` — `post.jpg`, `config.json`, `caption.txt` каждого поста
- `log.md` — журнал опубликованных постов (тема, источник, ссылка). Перед новым постом читать, темы не повторять.

## Стиль картинки
В тексте на картинке тоже только дефис «-», без «—».
Светлый фон с фиолетовым свечением, логотип слева сверху, метка-«пилюля» справа, заголовок с засечками (Lora),
одно слово-акцент фиолетовым `[[так]]`, белая карточка (график `bars` или список `points`), источник, фиолетовая бегущая строка.
- Формат с крупной цифрой (`big`) — для новостей и исследований с сильной цифрой.
- Без `big` + `points` — для советов, чек-листов, разборов.
- Заголовок 2–3 строки, коротко. Пункты по 1 строке. Не больше 5 строк графика.
- После рендера обязательно открыть картинку и проверить: ничего не вылезает, нет опечаток, цифры совпадают с источником.

## Правила текста (caption)
- Пишем как живой SMM-щик агентства, а не как нейросеть: короткие абзацы, разговорный тон, конкретика.
- Запрещено: «в современном мире», «давайте разберёмся», «важно отметить», «ключевой», «не просто X, а Y», «погрузимся», «в эпоху», списки из эмодзи, восклицательные знаки подряд, ИИ-пафос.
- Структура: цепляющая первая строка → суть и цифры с источником → что это значит для бизнеса → 2–4 практичных шага → вопрос к аудитории → 4–7 хэштегов.
- Тире: НИКОГДА не использовать длинное «—» и среднее «–». Всегда обычный дефис «-» (и в тексте, и на картинке, и в списках).
- Только проверенные факты из источника. Не выдумывать цифры, кейсы, клиентов и цитаты.
- В конце КАЖДОГО поста, через пустую строку, ровно этот блок:

```
🌐 https://dobroe.agency/
📞 +996 222 522 235
💬 https://t.me/Dobroe_agency
📨 ceo@dobroe.agency
```

## Темы - ротация рубрик
Каждый пост - из ДРУГОЙ рубрики, чем предыдущий. Одна рубрика - не чаще 1 раза из 5 последних постов (смотреть колонку «Рубрика» в log.md).
Подтема (конкретная мысль, исследование, совет) не повторяется никогда. Сначала выбрать рубрику, потом искать тему внутри неё.

1. **Новости площадок** - обновления Instagram, Telegram, TikTok, YouTube, WhatsApp, Threads (за последние 7 дней).
2. **Реклама** - Google Ads, Яндекс Директ, таргет Meta/TikTok: изменения, ставки, форматы, ошибки бюджета.
3. **SEO и сайты** - поиск, Google/Яндекс, скорость сайта, локальное SEO, Google Карты и 2ГИС.
4. **ИИ в маркетинге** - инструменты, исследования, как бизнес реально их использует.
5. **Цифры и исследования** - свежая статистика рынка, поведение покупателей, e-commerce, маркетплейсы.
6. **Чек-лист** - пошаговая проверка чего-то полезного (профиль, сайт, рекламный кабинет, воронка).
7. **Разбор мифа** - распространённое заблуждение в маркетинге и как на самом деле.
8. **Telegram для бизнеса** - боты, каналы, Mini Apps, автоматизация заявок.
9. **Контент и SMM** - идеи рубрик, сторис, Reels, работа с комментариями и отзывами.
10. **Аналитика** - GA4, UTM, сквозная аналитика, какие метрики смотреть.
11. **Рынок Кыргызстана и Центральной Азии** - digital-новости региона, локальные площадки, поведение аудитории.
12. **Продажи и заявки** - обработка лидов, скорость ответа, скрипты, CRM.

Форматы тоже чередовать: новость с цифрой (`big` + `bars`) ↔ совет/чек-лист (`points`) ↔ миф (`points`). Не больше 2 постов подряд одного формата.
Для новостей и исследований - только свежие (до 7 дней) и с первоисточником. Советы и мифы - без выдуманных цифр.

## Telegram-канал @Dobroe_agency
Тот же пост и та же картинка, что в Instagram, текст адаптирован под Telegram (файл `caption-tg.txt`, parse_mode HTML):
- первая фраза жирным `<b>...</b>`, подзаголовок списка тоже жирным;
- источник - активной ссылкой `<a href="URL">текст</a>` прямо в тексте;
- хэштеги 3-4 штуки;
- видимый текст (без HTML-тегов) не длиннее 1024 символов - лимит подписи к фото. Если не влезает - сократить, не обрезая смысл;
- в HTML экранировать `&`, `<`, `>` в обычном тексте (`&amp;` `&lt;` `&gt;`);
- контактный блок в конце:
```
🌐 <a href="https://dobroe.agency/">dobroe.agency</a>
📞 +996 222 522 235
💬 <a href="https://t.me/Dobroe_agency">@Dobroe_agency</a>
📨 ceo@dobroe.agency
```
