# Сторис @kitaj_rulit

Отдельная папка для Instagram @kitaj_rulit («Китай RUлит»). К автопостингу «Агентства Добрых Дел» не относится и его не затрагивает.

- `YYYY-MM-DD/HH-00.jpg` — готовая сторис 1080×1920, время публикации по Бишкеку.
- Публикует запланированная задача «Сторис Китай RUлит» через отдельный коннектор Instagram в AnythingMCP (id `cmvqpsoh3092s01o3u8bb7m5q`).
- `published.md` — журнал опубликованных сторис.
- ВК: те же сторис в той же задаче публикуются в истории сообщества vk.com/kitaj_rulit скриптом `vk_story.py` (с кнопкой «Подробнее» → kitaj-rulit.ru). Ключ сообщества хранится только в задаче, в репозиторий не пишется. Журнал — `vk-published.md`.
