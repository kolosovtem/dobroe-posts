# Сторис БСК (paneli.kg)

Отдельная папка для ежедневных сторис завода сэндвич-панелей **БСК** (Бишкекская сварочная компания, сайт https://paneli.kg, Instagram @bishkekwelding). К автопостингу «Агентства Добрых Дел» и @kitaj_rulit не относится и его не затрагивает: задачи БСК меняют файлы только внутри `bsk/`.

## Файлы
- `render.py` - рендер сторис 1080×1920 JPEG: `python3 -I bsk/render.py bsk/stories/<YYYY-MM-DD>/story.json bsk/stories/<YYYY-MM-DD>/story.jpg`
- `examples/*.json` + `*.jpg` - образцы пяти макетов (одобрены владельцем 03.11.2026).
- `topics.md` - контент-план по кругу (номер темы, макет, факты).
- `config.json` - куда публиковать (Telegram-канал, коннектор Instagram). Пустое поле = площадка не подключена, пропускаем.
- `published.md` - журнал: дата, номер темы, макет, ссылки/ID публикаций.
- `assets/` - шрифты сайта, фото завода и объектов с paneli.kg, логотипы. Не менять, не рисовать свой логотип.

## Стиль (как на paneli.kg)
Цвета: тёмно-синий `#0b2a63`, синий `#1358d8`, ледяной `#edf3fa`, линии `#d9e1eb`. Шрифты сайта BSK Display (заголовки, капсом) и BSK Text. Тонкая сетка на фоне, синие акценты, строгий промышленный вид. Реальные фото завода и объектов - никаких стоковых картинок и выдуманных объектов.

## Макеты (`layout`)
- `photo` - фото на весь экран с тёмно-синим затемнением, заголовок, текст, до 3 цифр `stats` [["число","подпись"]]. Поля: photo, focus (CSS background-position), kicker, title, text, stats, button, foot.
- `project` - фото объекта сверху + белая карточка: num, kicker, title, text, tags (2-3), button, foot.
- `compare` - две колонки со спецификациями: cols[{cutout или photo, label, name, rows[[k,v]], for}], text.
- `bignum` - огромное число + подпись + фото в рамке: number, size (по умолчанию 300, для длинных чисел 200-220), unit, text, photo, dark (true - тёмный фон).
- `tip` - фото сверху, заголовок и 3 коротких пункта: title, points (3 шт., по 2-5 слов).
В заголовках `|` - перенос строки, `*слово*` - синий акцент. Картинки - пути внутри `assets/` (`img/...`, `projects/...`).

## Правила
- Макет не повторяется 2 дня подряд; одно фото - не чаще раза в 10 дней (смотри `published.md`).
- На картинке максимум 40 слов (compare - 70). Заголовок 2-6 слов. Рендер сам падает при превышении и предупреждает, если текст заходит на кнопку или за край.
- Только дефис «-», без «—» и «–».
- Сверху ~250 px и снизу ~200 px перекрывает интерфейс Instagram - важный текст туда не ставить (макеты это уже учитывают).
- После рендера открыть story.jpg и проверить глазами: не обрезано, читается с телефона, нет опечаток, цифры совпадают с фактами ниже.
- Внизу всегда призыв (кнопка) и paneli.kg или телефон.
